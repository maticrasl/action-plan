# Reviews (feature 14, sessions A, B and C)

Built from `docs/features/14-reviews.md`; this records only what the build decided.

## Data

Journal reviews as 00-foundation defined them: `{ id, kind, period, doneAt, answers, updatedAt }`.
No new storage key, sync file version unchanged (the journal section exists since #49).

- week: `period '2026-W47'` (ISO week, the year of its Thursday); `answers { well, hard, focus: { plan, item, title } | null, stats }`.
- month: `period '2026-10'`; `answers { sentence, goals: { [goalId]: { plan, title, choice, from, to } }, stats }`.
- year: `period '2026'`; `answers { glad, differently, next, visions: { [visionId]: { title, choice } }, stats }`.
- `stats` is `{ steps, routineDays, values, goals }` (the done log's counts) at the moment of finishing.
- A second Finish of a period updates the review finished last for it (`latestReview`); no copy.
- Drafts: preference `reviewDraft.<period>` (per user, this device), text fields and, for month and
  year, each choice as a JSON line under `goal.<id>` / `vision.<id>`. Cleared on Finish.
- Fixture: `tests/fixtures/reviews.storage.json` (one review of each kind and a draft).

## Modules

- `core/reviews.ts`: which week, the focus week, ISO week names, Measure, Forgot to tick, Fix the plan
  (the tips' own `hits` for stuck-step, routine-low, goal-past, goal-behind, waiting; and `lateSteps`), the dot.
- `core/reviews-month.ts`: which month and year, `progressAt`, `monthKept` (16's `weekKept`).
- `core/reviews-year.ts`: the year's counts, goals reached with closing notes, biggest changes.
- `core/areas.ts`: `areaReport` takes a first day (default the last 30 days, as before).
- `views/review.ts` (switch, done log, clicks), `review-frame.ts` (head, sections, drafts, Finish),
  `review-week.ts`, `review-month.ts`, `review-year.ts`, `review-past.ts`.
- `store/journal.ts`: `setFocus` takes the week. `views/focus.ts`: the picker chooses for a given week.

## Choices made while building

- Forgot to tick lists routines with set days only; flexible routines (any days a week) have no due day
  (`shortcut:` comment in `core/reviews.ts`).
- Fix the plan's buttons open the item's plan first (Move late steps works on the open plan).
- Let it go on a goal of another plan opens that plan first, so Recently deleted names the right plan.
- Pause and Bring back act in the goal's plan without opening it.
- Biggest changes: the change over the larger of the two values (`shortcut:` comment in `core/reviews-year.ts`).
- Keep goals (07) show only their present share in the monthly review (no "from").
- The `month` tip's text now points at the monthly review; `new-year` opens the yearly review.
- The Guide's weekly checklist and its strings `guide.review.*` are gone; `seen.lastReview` is set by
  finishing a weekly review.
- Help tip `reviewTabs` on the switch.
