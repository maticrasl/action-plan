# Map tidy: fold levels, no Show/Status rows, map in the page

## What

1. Band labels lose "(n levels)".
2. Each band (Visions, Goals, Activities, Current states) can be folded. A folded band is a slim
   strip with its label and a ▸ button; its boxes and every line touching them are not drawn.
   The label/▾ button folds it again. Remembered and synced.
3. The "Show:" relationship chips and the "Status:" legend go. Every line type is always drawn;
   the old `mapHidden` preference is ignored from now on (left in storage, harmless). The zoom
   buttons move into the toolbar row.
4. The map is no longer a framed box with its own scrollbars: the page itself scrolls both ways.
   The sidebar stays in place (sticky) when scrolling right; the toolbar stays at the top-left
   (sticky both ways). Agreed with the owner 2026-11-20 (fold same in all plans, bars at bottom). The hint text under the map goes. The selection bar (Edit / Deselect) and the linking bar
   stick to the bottom of the screen, so they stay visible below a tall map.

## Data shape

New per-user preference `mapFold`: `{ kinds: ('vision'|'goal'|'activity'|'state')[], at: ISO }`.
Synced as an optional `mapFold` section of the sync file, like `tips`/`trash`: the later `at` wins.
Older versions ignore the unknown section; a file without it leaves the local value alone.
Per user, so the same bands are folded in every plan.

## Modules

`views/map/render.ts` (labels, fold strips, toolbar, bars), `views/map/layout.ts` (folded band
height, skip folded items), `store/` new `map-fold.ts`, `sync/sync.ts` (section), `views/events.ts`
